# Package index

## Core model functions

- [`prepare_weather()`](https://mr-eini.github.io/ThermoPheno/reference/prepare_weather.md)
  : Prepare daily weather data for ThermoPheno
- [`calc_daily_tt()`](https://mr-eini.github.io/ThermoPheno/reference/calc_daily_tt.md)
  : Calculate daily thermal time
- [`estimate_required_tt()`](https://mr-eini.github.io/ThermoPheno/reference/estimate_required_tt.md)
  : Estimate required thermal time from a reference baseline period
- [`estimate_required_tt_from_observed()`](https://mr-eini.github.io/ThermoPheno/reference/estimate_required_tt_from_observed.md)
  : Estimate required thermal time from observed planting and harvest
  dates
- [`find_planting_date()`](https://mr-eini.github.io/ThermoPheno/reference/find_planting_date.md)
  : Find the first planting date within an allowed planting window
- [`simulate_one_year()`](https://mr-eini.github.io/ThermoPheno/reference/simulate_one_year.md)
  : Simulate one crop season
- [`run_simulation()`](https://mr-eini.github.io/ThermoPheno/reference/run_simulation.md)
  : Run ThermoPheno simulations across all years in a weather data set
- [`default_parameters()`](https://mr-eini.github.io/ThermoPheno/reference/default_parameters.md)
  : Default ThermoPheno crop parameters

## Validation helpers

- [`compare_validation_metrics()`](https://mr-eini.github.io/ThermoPheno/reference/compare_validation_metrics.md)
  : Compare observed and simulated phenological dates
- [`validate_weather_dwd()`](https://mr-eini.github.io/ThermoPheno/reference/validate_weather_dwd.md)
  : Validate weather input against ThermoPheno and DWD-like conventions

- [`ThermoPheno()`](https://mr-eini.github.io/ThermoPheno/reference/ThermoPheno.md)
  : Launch the ThermoPheno Shiny application
